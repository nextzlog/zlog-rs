# Map data

`shapes.bin` and `jcc.tsv` are built by `../tools/build_data.py` from `jp.json` and `jcc.yaml` of https://github.com/jg1vpp/qth.zlog.org (MIT, see `LICENSE.qth.zlog.org`).
The version used is on the first line of `jcc.tsv`.
The boundaries in `jp.json` are simplified from the National Land Numerical Information administrative boundaries (国土交通省 国土数値情報 行政区域データ).
Credit: 出典: 国土交通省国土数値情報（行政区域データ）を加工して作成.
The source has no boundaries for Kanagawa, Wakayama and Kagoshima.
